Recent Update

The software package has recently been revised and reorganized to improve its usability and reproducibility. We have updated the analysis codes and provided compact, directly runnable example datasets for the main analysis modules. Corresponding validation figures are also included, allowing users to compare the outputs generated by the example scripts with the expected results. These materials are intended to provide a transparent and reproducible implementation of the key analysis methods applied in the associated study and to facilitate their use in related research.
